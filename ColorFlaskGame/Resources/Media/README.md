# Media Resources

Use this folder for source media files that are not stored in `Assets.xcassets`.

- `Images/`: reference images, exported PNG/JPG/WebP files, backgrounds, textures.
- `Music/`: longer audio tracks such as menu music or gameplay loops.
- `Sounds/`: short effects such as taps, pours, wins, errors, and transitions.

Prefer short, lowercase file names with hyphens, for example `pour-loop.wav`.
